# CASP4 Exemplar Template

## Standard CASP4 (event-triggered)

[CLIENT] is a [AGE]-year-old [GENDER] living [LIVING SITUATION]. [They have]
[DIAGNOSIS 1], [DIAGNOSIS 2], and [DIAGNOSIS 3 — if applicable]. [Their]
functioning is [FUNCTIONING DESCRIPTION — e.g. "heavily reliant on NDIS
support," "independent with informal family support," "declining over the
reporting period"]. [They are] supported by [SERVICE 1] and [SERVICE 2 — if
applicable]. Chronic risks include [RISK 1], [RISK 2], and [RISK 3 — if
applicable]. [CLIENT] is prescribed [MEDICATION 1] [DOSE], [MEDICATION 2]
[DOSE] [PRN if applicable], and [MEDICATION 3] [DOSE] [PRN if applicable].

Since [CLIENT] was last discussed on [DATE], [OPENING SENTENCE THAT STATES THE
REASON FOR PRESENTATION — the key event, risk, question, or unknown].
[Chronological narrative covering the period, including:]

- [KEY EVENT/S — what happened, when, who was involved]
- [CLINICAL OBSERVATIONS — mental state, engagement quality, presentation,
  self-care indicators]
- [RISK UPDATE — what's changed, what's emerged, what's stabilised, what's
  been ruled out]
- [ACTIONS TAKEN — referrals submitted, safety plans documented, family
  contacted, police/FVISS checks requested and outcomes, service coordination]
- [SYSTEMS/ADMIN — referral delays, funding issues, service coordination
  problems, who assisted in resolving them]
- [CLIENT'S PERSPECTIVE — what they want, their ambivalence, their goals,
  their insight, what they're keen to work on]
- [CURRENT STATE — where things stand now, what's pending, what's booked,
  what the clinician will do next]

[The formulation ends with the current state. The question or request for the
medical team is either stated or implicit in the presentation.]

## 91 Day Review Variant

91 Day Review

[CLIENT] is a [AGE]-year-old [GENDER] living [LIVING SITUATION]. [They have]
[DIAGNOSIS 1] and [DIAGNOSIS 2 — if applicable]. [They are] supported by
[SERVICE 1 — if applicable]. [CLIENT] is prescribed [MEDICATION 1] [DOSE].

The main event in [CLIENT]'s notes this period was [KEY EVENT — if any; if
none, state "no significant events"]. [Chronological summary of the 91-day
period, covering:]

- [SIGNIFICANT EVENTS — any incidents, changes, developments, or "no
  significant events to report"]
- [ENGAGEMENT — contacts completed, attempts made, cancellations, voicemails
  left, SMS sent]
- [RISK STATUS — current risk picture, any changes, any concerns]
- [MEDICATION — any changes, issues, reviews, ECG results if relevant]
- [PENDING ITEMS — upcoming reviews, referrals in progress, flagged items]

[A 91 Day Review may be briefer than an event-triggered CASP4. It still
includes the static summary and covers the period comprehensively. The purpose
is mandated oversight, not a specific clinical question.]

## Structural Notes (for the agent)

### Static Summary Paragraph — what stays, what changes

**Stays the same across presentations (update only when facts change):**
- Demographics (age, gender)
- Diagnoses (add new ones, don't remove old ones)
- Chronic/background risks
- Key context (relationship history, legal status)

**Update each presentation:**
- Living situation (if changed)
- Medications (dose changes, new medications, ceased medications)
- Functioning description (if notably changed)
- Supports/services (if new services engaged or old ones ceased)

### Attribution Conventions

- Clinician's own observations: stated as fact ("[CLIENT] was flat and
  dejected")
- Client's self-report: "[CLIENT] reports..." or "[CLIENT] denied..."
- Collateral information: "[COLLATERAL] advised..." or "[SERVICE] reports..."
- Police/FVISS: "A FVISS request returned..." or "Police records show..."
- The client's perspective vs clinician's view: distinguished explicitly
  ("[CLIENT] reports she is keen to start with CNV so YMHWS contact can be
  about mental health again" — this is the client's stated goal, not the
  clinician's assessment)

### Risk Language

- Chronic/background risks: stated in the static summary
- Acute risks: stated in the update with timeframe and context
- Risk ruled out: stated explicitly ("showed no signs of psychotic symptoms or
  suicidal ideation")
- Risk corroborated: note who confirmed ("corroborated by DS Nursing")
- Risk ambivalence: capture the client's mixed feelings without resolving them
  ("[CLIENT] not intending to end relationship at this point, confused and
  ambivalent")

### Medication Documentation in CASP4

- List all prescribed medications with doses in the static summary
- Note PRN status for each
- In the update: note any medication changes, periods off medication, side
  effects, compliance issues, or medication safety incidents
- Depot medications: note due dates and any changes to administration
  arrangements
- Self-prescribing or external prescriber issues: document urgently with the
  dose, source, and management steps taken
